# GWaveform 协议与可视化适配说明

本目录记录 GMSI 框架中 `gwaveform` 模块的协议定义及配套工具 `superwaveform` 的适配变动。

## 协议变动记录 (2026-04-18)

### 1. 数据同步优化
*   **问题**：由于 MCU 发送频率与 Host 处理频率不完全同步，波形常出现“推挤”或“断裂”现象。
*   **改进**：Host 端 `superwaveform` 引入了基于 LPF（低通滤波）的平滑虚拟时钟算法。协议层保持轻量，但在 Host 端增加了对包间隔的自适应估计。

### 2. 差值测量支持
*   为了支持 Host 端的 `Space` 测量功能，`gwaveform` 数据流现在被严格映射到时间序列。测量逻辑完全在 Host 端实现，无需修改 MCU 协议字节，保证了 MCU 端的零负载开销。

## Host 端工具 (superwaveform) 适配
配套工具已完成以下关键升级：
1.  **ImPlot 状态机修复**：修正了 `BeginPlot` 与 `Setup` 之间的顺序逻辑，解决了在切换窗口或数据重置时可能的断言失败。
2.  **多通道隔离**：支持 1-16 通道动态描述，Host 端自动根据协议包中的描述帧更新 UI 标签。
3.  **CSV 序列化**：录制格式统一为标准 CSV，时间戳使用双精度浮点数。

## 开发者注意
在 MCU 端调用 `gwaveform_send` 时，请确保采样率稳定。Host 端会根据收包间隔自动计算显示周期。若采样率发生剧烈变动，Host 端的 `Window` 缩放效果可能会受影响。
