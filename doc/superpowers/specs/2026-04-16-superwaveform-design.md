# SuperWaveform (虚拟示波器) 设计文档

## 1. 简介
一个基于 C++、SDL2、Dear ImGui 和 ImPlot 构建的高性能、精美的上位机波形查看与调试工具，专门对接 MODUS 框架的 RTT 网络输出。

## 2. 界面与布局设计 (16:9 比例)
默认窗口启动尺寸暂定为 `1280 x 720` (16:9)。

界面被划分为三大功能区：

1. **中央主波形区 (Waveform Display)**
   - 占据画面左上至中部约 `70%` 的面积。
   - 配置 ImPlot 实现：**鼠标左键拖拽平移**，**滚轮无级缩放**（可锁定轴），**右键框选放大**。
   - 支持动态图例、通道开关以及数据标尺跟踪。

2. **右侧日志栏 (Log Monitor - Ch0)**
   - 占据画面右侧约 `30%` 的竖向宽度。
   - 实时监听来自端口 `9090` (RTT Channel 0) 的数据，滚动展示 `MLOG` 等系统吐出的文本信息。
   - 底部提供“清空”、“自动滚屏”选项，保留一定的查看深度。

3. **底部交互终端 (Control Dashboard & Terminal)**
   - 横跨界面底部。
   - 包含快捷连接状态指示灯（Ch0 和 Ch1 的连接状态）。
   - 核心组件：一个命令行输入框，敲击回车直接将指令发往端口 `9090` (对接到固件中的 `mshell`)。
   - 附带自定义快捷按键 (如 `wave start`, `wave stop` 等常用宏)。

## 3. 核心机制

### 3.1 高频断线重连 (抢占式连接)
- 独立于界面渲染的后台探测线程，以每秒上百次的频率不断轮询 `localhost:9090` 和 `localhost:9091`。
- 上位机软件可以永久挂起，当下位机通过 `make auto` 引发 OpenOCD 启停时，上位机能在几十毫秒内立刻重新连入并抓取最初始的上电数据。

### 3.2 深度缓存与缓冲处理
- 对每个通道开辟支持存储数十万至上百万个单据的循环缓冲区（Circular Buffer）。
- 运用 ImPlot 对连续数组进行无拷贝的高速内存指针映射渲染能力，保证 60fps 丝毫不会卡顿。

### 3.3 协议解析
- 完全复用 MODUS 固件框架中已经定义好的 `protocol.c/h`，做到同一套序列化标准跨平台编译。

## 4. 技术栈限制与环境
- **底层图形渲染:** SDL2 (利用其跨平台窗体管理以及事件获取功能)。
- **UI & 渲染引擎:** Dear ImGui & ImPlot。
- **通信接口:** Native `<winsock2.h>` (仅面向 Windows 系统的高效 Socket 调用)。
- **编译工具:** `mingw-w64-x86_64-clang++`，独立编写一个 `Makefile.host` 将上位机代码编译并链接静态组件。

## 5. 后续演进
未来可以无缝集成触发器 (Trigger) 和标尺测量系统 (Cursors)，但初期先落实高强度可靠的数据承载和完美布局。
