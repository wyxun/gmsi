# 波形可视化优化与 Bug 修复总结 (2026-04)

本项目经历了从基础显示到专业分析工具的演进，以下是关键技术问题的复盘。

## 0. 波形质量优化 (Jitter & Aliasing)

### 0.1 阶梯状锯齿 (Staircase Artifacts)
*   **现象**：在高速采样或快速滚动时，波形呈现明显的阶梯状，不平滑。
*   **根因**：
    - **时间戳精度丢失**：数据包到达时间受网络随机抖动影响，导致绘制点在 X 轴分布不均。
    - **像素对齐问题**：绘图引擎在渲染时未进行亚像素插值。
*   **优化方案**：
    - **LPF 平滑时钟 (Adaptive Smoothing)**：上位机根据包总量动态估算采样周期，并在两帧之间进行时间维度的线性插值，视觉上消除“瞬移”感。
    - **亚像素渲染配置**：通过 `ImPlot` 设置确保波形线段具有抗锯齿特性。

### 0.2 数据重叠与闪烁
*   **现象**：在大数据量下，波形线段出现重叠感。
*   **优化**：引入了 `ScrollingBuffer` 环形队列，确保旧数据平滑淡出，新数据无缝接入。

## 1. 稳定性优化：彻底解决崩溃问题

### 1.1 ImPlot 断言失败 (Assertion Failure)
*   **现象**：程序在切换窗口、重置数据或缩放时发生随机闪退。
*   **根因**：ImPlot API 对调用顺序要求极严。交互逻辑（修改 Axis Limits）与绘图逻辑 (`PlotLine`) 顺序不当。
*   **修复方案**：强制 `BeginPlot` -> `SetupAxes` -> `SetupAxisLimits` -> `Interactions` -> `PlotLines` 序列。

### 1.2 ImGui Tooltip 栈崩溃
*   **根因**：错误的 `BeginTooltip()` 嵌套调用（Double Begin）。
*   **修复**：合并测量与坐标显示的逻辑，共享同一个 Tooltip 闭环。

## 2. 协议与并发优化 (核心避坑指南)

### 2.1 协议掩码对齐 (The Mask Bytes Mismatch)
*   **技术细节**：协议使用位掩码（Mask）来标识有效通道。
*   **致命 Bug**：下位机编译为 8 通道（1 字节 Mask），上位机预期 16 通道（2 字节 Mask）。
*   **后果**：上位机误将数据首字节当成第 2 个 Mask 字节。导致 `active_count` 错误，引发帧长计算连锁错误，造成 90% 以上的丢包率。
*   **经验**：必须严格同步两端的 `GWAVEFORM_MAX_CHANNELS` 配置。

### 2.2 生产者-消费者竞态消除 (SPSC Optimization)
*   **并发冲突**：下位机采样（SysTick 中断）是生产者，主循环（Poll）是消费者。采样中断可能在读取中途修改数据。
*   **优化方案**：
    - 在 `Commit` 阶段引入原子保护。
    - 移除冗余中断锁，利用 GMSI 环形缓冲区的 SPSC 特性。
    - 扩大单次读取块（128B -> 512B），减少 RTT 操作频率，降低 CPU 开销。

## 3. 性能上限与带宽分析

### 3.1 采样速率极限 (Sampling Rate)
*   **当前水平**：基于 `SysTick (1ms)`，稳定采样率为 **1000 Hz**。
*   **进阶上限**：若移至硬件定时器（Timer IRQ），采样率可达 **50kHz - 100kHz**。此时瓶颈将移至 RTT 传输带宽。

### 3.2 传输带宽瓶颈 (RTT Throughput)
*   **硬件限制**：
    - **原生 J-Link V11/Pro**：带宽可达 500KB/s+，支持多通道高频全开。
    - **集成式调试器 (DAP-Link/ST-Link)**：带宽通常在 20KB/s 左右。一旦超过此限制，下位机将进入频繁阻塞状态。

## 4. 故障排查与维护建议

| 现象 | 可能原因 | 修复建议 |
| :--- | :--- | :--- |
| **波形出现直线/断裂** | 环形缓冲区溢出 | 提高 `Poll` 频率或降低采样率 |
| **采样率显示异常** | 协议掩码两端不匹配 | 检查两端 `MAX_CHANNELS` 宏定义 |
| **Legend 丢失** | 错过描述帧 | 等待 1 秒待系统自动重发描述帧 |
| **波形更新卡顿** | 带宽爆满 | 降低采样频率或减小 RTT 数据块大小 |
