# SuperWaveform 高性能波形显示系统：优化与极限分析报告

## 1. 架构总览 (Architecture Overview)

SuperWaveform 的数据链路遵循以下流水线：
`MCU 采样 (Interrupt)` -> `环形缓冲区 (SPSC Buffer)` -> `RTT 传输 (Debug Link)` -> `上位机解析 (Protocol Parser)` -> `时钟同步与插值 (Virtual Clock)` -> `GPU 渲染 (ImPlot)`。

本次优化的核心目标是消除整个链路中的**不确定性（Jitter）**与**协议不一致（Misalignment）**。

---

## 2. 深度技术修复

### 2.1 协议掩码对齐 (The Mask Bytes Mismatch)
*   **技术细节**：协议使用位掩码（Mask）来标识哪些通道在当前帧中有效。
    *   **错误逻辑**：下位机编译时 `GWAVEFORM_MAX_CHANNELS` 为 8（1 字节 Mask），而上位机预期 16（2 字节 Mask）。
    *   **后果**：上位机误将第 1 个数据字节当成了第 2 个 Mask 字节。这导致 `active_count`（有效通道计数值）计算错误，进而引发**帧长计算连锁错误**。解析器为了寻找下一帧，会跳过并删除缓冲区中后续的合法帧，造成约 66%~90% 的丢包率。
    *   **修复方案**：通过 16 进制原始数据审计确认了下位机实际物理输出，强制同步两端为 8 通道模式。

### 2.2 生产者-消费者竞态消除 (SPSC Optimization)
*   **并发冲突**：下位机采样（SysTick 中断）是生产者，主循环（Poll）是消费者。在没有保护的情况下，采样中断可能在 Poll 读取缓冲区的中途修改数据。
*   **优化方案**：
    *   在 `Commit` 阶段引入原子保护。
    *   优化 `Poll` 逻辑，移除冗余的中断锁，利用 GMSI 环形缓冲区的 SPSC（单生产者单消费者）特性，通过扩大单次读取块（从 128 字节提升至 512 字节）来减少 RTT 操作频率，降低 CPU 开销。

### 2.3 调试链路可靠性 (RTT Robustness)
*   **模式切换**：将 RTT 模式从 `NO_BLOCK_SKIP` 切换为 `BLOCK_IF_FIFO_FULL`。
*   **权衡分析**：阻塞模式保证了数据的完整性。在调试链路带宽不足时，下位机主循环会短时间等待 RTT 发送空间，这比直接丢包导致的波形断裂更易于上位机通过插值算法修复。

## 3. 性能极限与瓶颈分析

### 3.1 采样速率极限 (Sampling Rate)
*   **当前水平**：基于 `SysTick (1ms)`，稳定采样率为 **1000 Hz**。
*   **进阶上限**：若移至硬件定时器（Timer IRQ），采样率可达 **50kHz - 100kHz**。此时瓶颈将移至 RTT 传输带宽。

### 3.2 传输带宽瓶颈 (RTT Throughput)
*   **数据量计算**：
    *   1kHz / 2ch：~9 KB/s（极度稳健）
    *   10kHz / 8ch：~190 KB/s（接近普通 ST-Link 的极限）
*   **硬件限制**：
    *   **原生 J-Link V11/Pro**：带宽可达 500KB/s+，支持多通道高频全开。
    *   **集成式调试器 (DAP-Link/ST-Link)**：带宽通常在 20KB/s 左右。一旦超过此限制，下位机将进入频繁阻塞状态。

### 3.3 视觉平滑度极限 (Rendering Fidelity)
*   **时钟抖动 (Jitter)**：由于 J-Link 轮询 RTT 的时间不固定，数据包到达上位机往往是“成阵发送”的。
*   **解决方案**：上位机实现了**虚拟时钟同步算法**。它根据接收到的包总量动态估算采样周期，并在两帧之间进行时间维度的线性插值，从而在视觉上消除因通信延迟导致的波形“瞬移”感。

## 4. 故障排查与维护建议

| 现象 | 可能原因 | 修复建议 |
| :--- | :--- | :--- |
| **波形出现直线/断裂** | 环形缓冲区溢出 | 提高 `Poll` 频率或使用 `wave rate 2` 降低频率 |
| **采样率显示异常** | 协议掩码或帧结构不匹配 | 检查 `GWAVEFORM_MAX_CHANNELS` 是否两端一致 |
| **Legend (Sine/Cosine) 丢失** | 错过描述帧 | 系统已具备每秒重发机制，请等待 1 秒或手动重连 |
| **波形更新卡顿** | 调试链路带宽爆满 | 降低采样频率或减小 RTT 数据块大小 |
