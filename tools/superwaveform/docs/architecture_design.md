# SuperWaveform 架构设计说明

本文档面向希望了解 SuperWaveform 内部实现或进行二次开发的开发者。

## 1. 技术栈
SuperWaveform 选择了高性能且跨平台的组合：
- **核心语言**：C++ 17
- **图形库**：SDL2 (用于窗口管理与输入处理)
- **UI 框架**：Dear ImGui (Docking 分支，用于多窗口布局)
- **绘图后端**：ImPlot (专为高性能曲线渲染设计的 ImGui 扩展)
- **渲染 API**：OpenGL 3.0 (硬件加速渲染)
- **网络通信**：Native Winsock2 (高性能非阻塞 TCP 客户端)

## 2. 核心模块设计

软件采用了高内聚、低耦合的设计，主要分为三个层级：

### A. NetworkMgr (通信层)
- **设计模式**：单例模式 (Singleton)。
- **多线程逻辑**：启动了两个独立的后台线程，分别负责 RTT Channel 0 和 Channel 1 的 TCP 连接。
- **鲁棒性**：实现了自动重连机制。通过 `select()` 函数实现非阻塞轮询，确保网络波动或板子复位时，UI 线程不会产生任何卡顿。

### B. ProtocolParser (协议解析层)
- **职责**：将网络线程收到的原始字节流还原为具有物理意义的数据帧。
- **状态机**：实现了轻量级的帧同步逻辑（寻找 `0xAA 0x55`），处理变长的数据载荷。
- **动态描述**：支持动态解析下位机发来的描述帧，自动更新通道名称和缩放比例。

### C. GuiLayer (展示层)
- **ScrollingBuffer**：为了支持百万级点位的平滑显示，自定义了环形缓冲区结构。
- **即时模式 UI**：利用 ImGui 的特性，每一帧都根据最新数据重新绘制，配合 OpenGL 硬件加速，即使在数据密集推送时也能保持 60 FPS 以上的帧率。
- **交互逻辑**：封装了 ImPlot 的坐标转换 API，实现了与示波器类似的时间轴缩放与平移功能。

## 3. 性能优化要点

1. **零拷贝思路**：数据从网络层读取后，直接存入环形缓冲区，渲染时直接引用，减少不必要的内存拷贝。
2. **非阻塞 IO**：网络读写完全异步，UI 线程只负责“取走”已解析好的数据快照。
3. **硬件加速**：波形渲染由 GPU 完成，极大地降低了 CPU 占用。

## 4. 依赖管理
项目通过 `git submodule` 管理 `imgui` 和 `implot`，这确保了 SuperWaveform 可以作为一个独立的工具轻松移植到其他基于 GMSI 的工程中。
