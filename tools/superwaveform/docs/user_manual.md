# SuperWaveform 用户操作手册

## 1. 快速入门
1. 启动 J-Link RTT 或 OpenOCD。
2. 运行 `superwaveform.exe`。
3. 如果连接成功，Dashboard 会显示 `[Ch1 Wave: ON]`。

## 2. 界面布局
*   **Dashboard (左侧)**：显示连接状态、终端日志。
*   **Oscilloscope (主窗)**：实时波形显示区。
*   **Offline Viewers (弹窗)**：通过 `Open CSV Viewer` 开启的历史记录分析窗。

## 3. 实时分析操作
*   **Window (滑块)**：调节当前显示的波形时长（0.1s - 60s）。
*   **Pause**：点击暂停波形刷新，此时测量功能依然有效。
*   **Clear**：清除当前所有通道的内存缓冲区。

## 4. 测量功能 (核心)
在任何 Plot 窗口（实时或离线）中：
1. **坐标查看**：鼠标悬停在波形上，黄色虚线十字准心会自动跟随，并在浮窗中显示 X (s) 和 Y 值。
2. **差值测量 (Space)**：
   - 将鼠标移动到起始点，按下 **Space** 键。此时起始位置会锁定一个红色虚线十字。
   - 移动鼠标，浮窗将实时显示：
     - `dX`: 当前点与参考点的时间差。
     - `Hz`: 自动换算的频率值（1/dX）。
     - `dY`: 两点之间的幅值差。
   - 再次按下 **Space** 键，清除参考点。

## 5. 离线分析
*   **缩放**：按住 `Ctrl` 键并滚动鼠标滚轮。
*   **平移**：在波形区域按住鼠标左键并拖拽。
*   **对比**：可以同时打开多个 CSV 窗口，每个窗口会自动分配独特的标题栏颜色。

## 6. 数据录制
*   **Start CSV**：点击右侧绿色按钮开始录制。
*   **保存位置**：文件保存在程序运行目录下，名为 `rec_年月日_时分秒.csv`。
*   **停止**：录制时按钮变红，点击 `Stop CSV` 结束录制。

## 7. Shell 宏命令
通过 `macros.ini` 文件可定义快捷按钮，向 Shell 通道 (Ch0) 发送预设指令。

### 配置文件格式
编辑 `.ini` 文件，每行定义一个宏，格式为 `显示标签 = 发送指令`：
```ini
# 这是注释
wave start = wave start
wave stop  = wave stop
wave speed = wave rate 4
```

### 操作流程
1. 点击 Dashboard 中的 **Load Macros...** 按钮，选择 `.ini` 文件。
2. 加载成功后，文件名会显示在按钮右侧，按钮栏会生成对应的快捷按钮。
3. 点击按钮即可向 Shell 发送指令（自动追加换行符）。
4. 程序退出时会记住上次加载的文件，下次启动自动恢复。

### 应用场景
* **调试命令行**：将常用的调试命令一键发送，如 `log -T`。
* **参数调节**：快速下发配置指令，如 `wave rate 4` 调整波形速率。
