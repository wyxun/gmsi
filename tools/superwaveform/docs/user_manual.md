# SuperWaveform 用户手册

## 界面布局说明

SuperWaveform 采用了 16:9 的分栏布局，确保波形观察和终端调试互不干扰。

### 1. Oscilloscope (中央绘图区)
这是工具的核心区域。
- **多通道渲染**：支持同时绘制多个数据通道。
- **实时刷新**：默认情况下，波形会跟随时间轴向右滚动。
- **自动坐标**：纵轴会根据数据范围自动调整或保持固定量程。

### 2. GShell Terminal (右侧边栏)
继承自 GMSI 的 Shell 监控功能。
- **实时 Log**：显示来自 RTT Channel 0 的所有打印信息。
- **交互输入**：底部的输入框可直接向板子发送 Shell 指令。
- **自动滚屏**：默认开启，方便观察最新状态。

### 3. Dashboard (控制面板)
位于窗口顶部，提供全局控制。
- **连接状态 (LED)**：绿灯表示 RTT 通道正常连接，红灯表示连接断开或 OpenOCD 未就绪。
- **Pause/Resume**：点击暂停后，波形停止刷新，此时可以自由回溯历史。
- **Time Window**：拖动滑动条可调整屏幕内显示的时间跨度（1秒到 60秒）。
- **User Macros**：预设的快速指令按钮（如 `wave start`, `log -I`）。

## 交互技巧

为了提供接近物理示波器的体验，SuperWaveform 支持丰富的鼠标交互：

- **缩放时间轴**：将鼠标悬停在波形区，使用 **鼠标滚轮**。
  - 向前滚动：放大（缩短显示时间，观察细节）。
  - 向后滚动：缩小（延长显示时间，观察趋势）。
- **平移波形**：在 **Pause (暂停)** 状态下，按住 **鼠标右键** 并拖拽。
- **清除数据**：点击 **Clear Waveform Buffer** 将清空本地缓存的所有历史数据。

## 故障排查
- **界面一片空白**：请检查 RTT 服务器（OpenOCD 或 JLink）是否已启动，并确认端口 9090 和 9091 是否被其他软件占用。
