# SuperWaveform 功能全集

SuperWaveform 是一款基于 ImGui 和 ImPlot 开发的高性能、实时/离线双模式波形分析工具。它专为嵌入式调试设计，支持多通道同步显示、精密数据测量及实验数据录制。

## 核心功能

### 1. 实时监控模式 (Real-time Oscilloscope)
*   **高性能渲染**：支持数万点级别的波形平滑刷新。
*   **自适应时钟**：内置虚拟时钟平滑算法，解决网络抖动导致的波形跳变问题。
*   **时间窗口调节**：支持 0.1s 至 60s 的动态时间窗口缩放（通过 Window 滑块）。
*   **波形锁定**：一键 `Pause` 锁定波形，方便在静态状态下进行精细观察。

### 2. 交互式测量工具 (Space Tool)
*   **虚线十字准心 (Dashed Crosshairs)**：动态跟随鼠标的黄色虚线，实时显示 X/Y 坐标。
*   **差值测量**：按下 `Space` 键锁定红色参考虚线，实时计算当前鼠标点与参考点之间的：
    *   **dX (时间差)**：单位秒。
    *   **Frequency (频率)**：自动计算 $1/dX$（Hz）。
    *   **dY (幅值差)**：直观查看信号波动范围。
*   **框选区域**：锁定后自动阴影填充测量区域，视觉化呈现数据区间。

### 3. 离线分析专家 (Offline Viewer)
*   **多窗口对比**：支持同时打开多个 CSV 文件，每个窗口独立运行。
*   **窗口调色**：不同离线窗口自动分配不同的蓝-青渐变色标题栏，方便区分不同批次的实验数据。
*   **智能缩放与平移**：
    *   `Ctrl + 滚轮`：以鼠标为中心进行 X 轴缩放。
    *   `左键拖拽`：在波形内自由平移查看历史细节。

### 4. 实验数据录制 (CSV Recording)
*   **一键录制**：控制栏右侧醒目的 `Start CSV` 按钮。
*   **规范化命名**：文件名自动格式化为 `rec_YYYYMMDD_HHMMSS.csv`，方便数据归档。
*   **安全状态反馈**：录制中按钮变为红色并提示 `Stop CSV`，防止误点。

## 操作指南

| 操作 | 功能 |
| :--- | :--- |
| **Space** | 开启/关闭 差值测量模式 |
| **Ctrl + Scroll** | X 轴缩放（仅离线模式） |
| **Left Drag** | 波形平移（仅离线模式） |
| **Pause/Resume** | 锁定/恢复 实时波形 |
| **Clear** | 清空实时缓存 |

## 技术特性
*   **蓝黑科技格调**：深度定制的 ImGui Premium Dark 主题。
*   **鲁棒性**：严格的 ImPlot API 调用序列管理，杜绝状态机断言崩溃。
*   **跨平台基础**：基于 SDL2 + OpenGL3，兼容 Windows/Linux。
